## Dokumentasi Screenshot

Seluruh hasil screenshot dari query, struktur tabel, dan hasil JOIN disimpan dalam folder `images` dengan pembagian sebagai berikut:

### 📁 images/tugas1
Berisi screenshot hasil query eksplorasi database, meliputi:
- Statistik buku
- Filter dan pencarian
- Grouping dan agregasi
- Update data
- Laporan khusus

### 📁 images/tugas2
Berisi screenshot hasil desain database, meliputi:
- Struktur tabel (kategori_buku, penerbit, buku, dll)
- Data pada setiap tabel
- Hasil query JOIN
- Detail lengkap database

### 📁 ERD
Berisi gambar Entity Relationship Diagram (ERD) yang menunjukkan relasi antar tabel dalam database.
